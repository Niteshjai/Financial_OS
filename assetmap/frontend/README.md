# AssetMap Frontend - Developer Guide

Welcome to the AssetMap Frontend! This document explains the architecture, features, and workflow for developers building the user interface.

## Tech Stack Overview
- **Framework:** React 18 with Vite
- **Language:** TypeScript
- **State Management:** Zustand
- **Styling:** TailwindCSS v4 with a custom Design System (see `index.css`)
- **Routing:** React Router v6
- **Data Visualization:** D3.js (Net Worth charts)
- **Maps:** Leaflet.js (`react-leaflet`)

## Complete Feature Set

### 1. Authentication & Onboarding
- **Aadhaar OKYC Login:** Multi-step secure authentication using Aadhaar and OTP.
- **DPDP Act Compliance UI:** Plain-language consent screens and "Right to Erasure" options in settings.

### 2. Core Dashboard & Account Aggregation
- **AA Consent Flow:** Redirects to Setu AA Web SDK to authorize data sharing.
- **Unified Net Worth View:** Summarizes Bank Deposits, Stocks, Mutual Funds, NPS, and Insurance Policies in a single interface.
- **Categorized Asset Breakdowns:** Detailed lists and tables for each financial asset type fetched securely from the backend.

### 3. Real Estate & Property Mapping
- **Surepass Land Records:** Displays officially registered land parcels linked to the user's Aadhaar.
- **Interactive Estate Map:** Leaflet-powered GIS map that visualizes land coordinates, boundaries, and estimated property values.
- **Manual Property Search:** Interface to manually search for property records by state/district/village.

### 4. Consumer Engagement & Security Suite
- **Interactive Net Worth Tracker:** D3.js powered area chart tracking historical net worth over 6m/12m/24m periods, including all-time highs and percentage changes.
- **Asset Change Alerts (Live Feed):** Real-time feed of system-generated alerts for massive balance drops (>20%), newly linked fraudulent accounts, and sudden land registry changes.
- **Alerts Bell:** Real-time unread notification indicator.
- **Nominee Checker Dashboard:** Scans all linked financial accounts and visually flags those missing registered nominees (to comply with RBI Dec 2025 mandates).
- **Unified Nominee Update Platform:** Allows users to fill out a single form to update missing nominees across all un-secured assets at once, syncing directly with Mutual Funds, KRA, and Banks asynchronously.
- **Dormant Account Finder:** Identifies accounts with 0 activity for over 12 months. Calculates and highlights the risk of funds being transferred to the IEPF (Investor Education and Protection Fund) after 7 years.
- **Notification Preferences:** UI to toggle SMS and Push Notifications for specific alert types.

### 5. Reporting
- **PDF Report Generation:** One-click download of a comprehensive "Asset Summary" PDF generated by the backend.

## How It Works (The Developer Workflow)

### 1. Authentication Flow
- The user inputs their Aadhaar in the `Login` page.
- We call `api.post('/auth/aadhaar/initiate')`.
- User inputs OTP -> `api.post('/auth/aadhaar/verify')`.
- The backend sets `httpOnly` cookies containing the JWT.
- Zustand store (`useAuthStore`) triggers `checkAuth()` to fetch the user's identity and update global state.

### 2. The Dashboard & Data Fetching
- Once authenticated, the user lands on the Dashboard.
- The app checks if AA Consent exists (`/consent/status`). If not, it redirects the user to the Setu AA Web SDK.
- Once consent is ACTIVE, the Dashboard pulls the `AssetSummary`, `NetWorthHistory`, and Engagement features in parallel.
- Data fetching logic is wrapped in `useEffect` hooks within components, calling the `api` service (which automatically attaches cookies).

### 3. Styling & Theming
- Do not use random hex colors. We use CSS variables defined in `index.css` (e.g., `var(--primary)`, `var(--surface-1)`).
- Tailwind classes are used for layout (`flex`, `grid`, `p-4`), while complex dynamic styles or deep customizations often use inline styles mapped to the CSS variables.

## Running Locally
```bash
npm install
npm run dev
```
Runs on `http://localhost:5173`. Ensure the Fastify backend is running concurrently on port 3000.
